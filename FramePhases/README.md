# FramePhases

This project implements the Jetpack Compose phase experiments from the practice task: composition, layout, and drawing.

It contains demo screens for:
- LectureTree
- PaddingDemo
- OffsetDemo
- ColorDemo
- ParallaxSlow / ParallaxFast
- ScrollToTopNaive
- Parent / Child / Sibling
- CyclicDemo / CyclicFixed
- StackBelow

Open the app and use the chips above the demo area to switch between examples. Each demo prints log output tagged by phase or behavior so the Compose lifecycle can be inspected in Logcat.
